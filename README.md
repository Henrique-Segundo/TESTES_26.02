# TESTES_26.02
Repositório para as atividades da disciplina de teste de software do semestre 26.02

# Para o "Exercícios – Testes unitários"
1) Verificar o Python com "python --version" ou "python3 --version", caso esteja ausente instale
2) Instalar o Pytest com "pip install pytest"
3) No terminal, realizar os testes com "python -m pytest" , os resultados com um ponto final "." é um teste bem sucedido e uma letra F em maiusculo "F" é um teste falho
