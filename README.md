A atividade continua a pratica anterior, onde os codigos base foram transformados em codigo python com o uso de IA e foram realizados os testes propostos no documento final da atividade anterior.

Para realizar os testes:
1) Verificar o Python com "python --version" ou "python3 --version", atualize caso necessario e caso esteja ausente instale
2) Instalar o Pytest com "pip install pytest"
3) No terminal, realizar os testes com "python -m pytest" , os resultados com um ponto final "." é um teste bem sucedido e uma letra F em maiusculo "F" é um teste falho
4) Instalar o Pytest COV com "python pytest-cov"
5) No terminal, realizar os testes com "python pytest--cov", ele mostra a cobertura dos arquivos orginais e dos arquivos de testes
